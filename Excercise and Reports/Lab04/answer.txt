12. Sort media in the cart
- What class should implement the Comparable interface?
Media Class, because Media is the most common superclass of Disc, CompactDisc and DigitalVideoDisc. By making Media comparable, all subclasses automatically inherit the ability to be compared.

- In those classes, how should you implement the compareTo()method be to reflect the ordering that we
want?
In Media, override compareTo() to define a requested ordering. For example with MediaComparatorByTitleCost, we sort by title first, then by cost (descending)

- Can we have two ordering rules of the item (by title then cost and by cost then title) if we use this
Comparable interface approach?
Comparable only allows one natural ordering per class (defined in compareTo()). If you need multiple sorting strategies, you must use Comparator objects instead.
→ That’s why the lab suggests creating MediaComparatorByTitleCost and MediaComparatorByCostTitle.
