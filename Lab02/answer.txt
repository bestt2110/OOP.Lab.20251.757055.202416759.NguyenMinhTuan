- If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this?
The answer is no. In the declaration part, we decide to give both category and title the same type of data which is String. So if you choose "title" and "category" to build constructors like DVD(String title) and DVD(String category) and it comes to the progress of using it in main(), JAVA can't distinguish between them and it directly notifies an error. To fix this problem, we can define each "category" by number then choose the type of "category" as a numerical one.
